# CallMeMaybe Research Roadmap

This fork is being used to push C++26 runtime reflection beyond library maintenance into reproducible systems research.

## Tracks

- Runtime reflection benchmark suite against hand-written and established dispatch approaches.
- Differential reflection fuzzer for GCC and Clang/P2996 behavior.
- Compile-time registry construction with a zero-registration runtime view.
- C++26 reflection to Flow binding generation.
- Reproducible report containing performance results, discovered pathologies, fixes, and upstream-ready patches.

Each track is issue-driven and must finish with tests, CI, and results captured in the repository.
